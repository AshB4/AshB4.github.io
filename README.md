## Featured Work

### True Fidelity Healthcare Advisors
Accessible healthcare and insurance comparison platform focused on helping senior users understand plan options with less friction.

### N8tiveFlow / PostPunk
Multi-platform publishing operations and content automation system for lifecycle tracking, metadata workflows, syndication planning, and evergreen content management.

### LaStormMapr
Hurricane preparedness and response dashboard for Louisiana residents, combining map-based shelter/resource visibility with checklist tools and local-first emergency planning.

### TurboVetChallenge
Secure multi-role task management system using JWT authentication, RBAC guards, protected routes, and Nx architecture.

### Oris-Verba
Real-time speech transcription project using OpenAI Whisper with closed-captioning capabilities.
